# Acento iOS

Native SwiftUI foundation for Acento.

## Direction

- SwiftUI-first.
- Dark Mode from day one.
- Haptics for lesson completion, practice feedback, and pronunciation recording states.
- Offline lesson/audio storage in a future phase.
- Widgets for streak, daily lesson, and review reminders in a future phase.

## Current Foundation

- App entry point.
- Premium tab shell.
- Lesson card view.
- Audio control placeholder.
- Shared product model types mirrored from `packages/shared`.

Open `AcentoApp.swift` in a SwiftUI project or move these files into an Xcode target when the native app is promoted from scaffold to build target.
