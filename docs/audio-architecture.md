# Audio Architecture

Every phrase is modeled for audio even before recordings exist.

## Required Audio Variants

- Slow audio.
- Native speed.
- Male voice.
- Female voice.
- Future community recordings.

## Playback Features

- Waveform UI.
- Playback speed.
- Download for offline.
- Pronunciation recording.
- Future speech feedback.

## Metadata

Future audio records should include:

- Phrase ID.
- Dialect.
- Speaker region.
- Speaker gender if volunteered.
- Speed.
- Recording source.
- Consent status.
- Review status.
