# Acento Android

Native Android foundation for Acento using Jetpack Compose and Material 3.

## Direction

- Compose-first UI.
- Material 3 with Acento-specific tokens.
- Offline lesson/audio storage in a future phase.
- Speech practice and conversation modes in future phases.

## Current Foundation

- Gradle project scaffold.
- Compose activity.
- Bottom navigation structure.
- Lesson card and audio placeholder components.

This scaffold is intentionally minimal so the product architecture can be reviewed before expanding the full Android build.
